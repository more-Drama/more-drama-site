# Πρώτο λειτουργικό δείγμα

Το έργο βρίσκεται στον φάκελο website του moreDrama Project, σε τοπικό κλάδο codex/functional-preview. Προέρχεται από το αρχικό αποθετήριο της Επιφάνειας εργασίας. Δεν έχει γίνει push ή deployment.

## Καθημερινή επεξεργασία

Το src/content/stories/kyriaki.json είναι η κοινή καταχώριση για τον τίτλο, την εισαγωγή, την περίληψη κάρτας, την εικόνα, τα κείμενα, τις λεζάντες, τα αποσπάσματα και τα στοιχεία SEO της συνέντευξης. Το schema βρίσκεται στο src/content.config.ts.

Η αρχική, το /people/ και το /people/i-poli-sta-cheria-tis/ χρησιμοποιούν αυτή την καταχώριση. Η διάταξη παραμένει βασισμένη στις εγκεκριμένες μακέτες. Τα υπόλοιπα 30 URLs κάτω από /preview/ διατηρούν τα προηγούμενα προσχέδια ώστε να λειτουργούν οι σύνδεσμοι του μενού. Η πλήρης μεταφορά του περιεχομένου τους σε συλλογές εκκρεμεί.

Τα δεδομένα που αποθηκεύτηκαν στον δοκιμαστικό editor του browser δεν μεταφέρθηκαν. Οι παλιές μακέτες παραμένουν διαθέσιμες στον αρχικό φάκελο.

## Εκτέλεση

- npm run dev για ζωντανή τοπική επεξεργασία.
- npm run build για παραγωγή των σελίδων.
- npm run preview για τοπική προβολή της κατασκευασμένης έκδοσης.
- node scripts/check-pilot.mjs για δοκιμή κοινής ενημέρωσης τίτλου και εικόνας. Ο έλεγχος αποκαθιστά το αρχικό περιεχόμενο και ξαναχτίζει το δείγμα.

Η προεπισκόπηση ακούει μόνο στο 127.0.0.1. Όλες οι σελίδες φέρουν noindex,nofollow και το δοκιμαστικό άρθρο είναι draft. Η δημόσια κυκλοφορία χρειάζεται ξεχωριστή διαδικασία έγκρισης και αποκλεισμό ανεγκεκριμένων προσχεδίων από το build. Το noindex δεν αντικαθιστά έλεγχο πρόσβασης σε μελλοντικό online staging.

## Έλεγχοι

Το build παράγει 33 σελίδες. Επαληθεύτηκε σε browser η διαδρομή αρχική → more People → άρθρο → more People σε πλάτη 390 και 1280 px χωρίς σφάλματα JavaScript. Επαληθεύτηκε επίσης ότι αλλαγή τίτλου και εξωφύλλου στο αρχείο της ιστορίας ενημερώνει και τις τρεις σελίδες.

Οι εικόνες και οι γραμματοσειρές εξήχθησαν από τις ενσωματωμένες μακέτες σε κοινά αρχεία. Τα τέσσερα βασικά assets της Κυριακής έχουν περιγραφικά ονόματα. Η περαιτέρω παραγωγή responsive παραλλαγών, ο καθαρισμός του παλιού CSS και η μεταφορά όλων των άρθρων εκκρεμούν.

## Θέματα πριν από δημόσια έκδοση

- Το npm audit αναφέρει ευπάθεια ReDoS στην έμμεση εξάρτηση picomatch και τη μεταδίδει ως προειδοποίηση σε δέκα πακέτα του εργαλείου κατασκευής. Η προτεινόμενη αυτόματη λύση υποβαθμίζει το Astro σε 5.3.0. Η απόπειρα εγκατάστασης picomatch 4.0.8 επέστρεψε μη διαθέσιμη έκδοση. Το package.json δεν κρατά αυτή την αλλαγή. Χρειάζεται επανέλεγχος διαθέσιμου διορθωμένου dependency tree πριν από εγκατάσταση σε δημόσια υποδομή ή CI με μη έμπιστες εισόδους.
- Οι φόρμες συνεχίζουν να είναι δοκιμαστικές.
- Η κύρια διεύθυνση, το sitemap και η σήμανση Article θα ενεργοποιηθούν για το εγκεκριμένο πραγματικό περιεχόμενο. Η μακέτα της Κυριακής είναι επινοημένη.
- Η άδεια web της GB-Stefania χρειάζεται επιβεβαίωση πριν από δημόσια χρήση.

## Δελτίο SEO δείγματος

Στόχος εργασίας είναι η παρουσίαση εργαστηρίου κεραμικής στη Δράμα. Η φράση «κεραμική στη Δράμα» είναι πρόταση χωρίς μέτρηση όγκου αναζητήσεων. Το δοκιμαστικό URL είναι /people/i-poli-sta-cheria-tis/. Για πραγματική επιχείρηση θα συμφωνηθεί περιγραφικό τελικό slug πριν δημοσιευτεί.

Τίτλος αναζήτησης «Κεραμική στη Δράμα — Η πόλη στα χέρια της | more Drama».
H1 «Η πόλη στα χέρια της».
Περιγραφή «Ένα πρωινό στο εργαστήρι της Κυριακής, από το πρώτο γύρισμα του τροχού ως τον καφέ στο παράθυρο».

| Αρχείο | Alt της καταχώρισης |
| --- | --- |
| keramistria-drama-ergastirio.webp | Κεραμίστρια στο εργαστήρι της, ενδεικτικό πορτρέτο AI |
| keramiki-drama-trochos.webp | Δάχτυλα που δίνουν σχήμα στο χείλος ενός μπολ |
| ergastirio-keramikis-drama.webp | Το φως από το παράθυρο πέφτει στον πάγκο του εργαστηρίου |
| keramika-rafi-drama.webp | Άψητα κεραμικά στο ράφι |
