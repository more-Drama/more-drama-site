# MORE DRAMA — website

Ελληνόφωνο, mobile-first editorial site για τη Δράμα. Βάση προδιαγραφών: Master Blueprint v1.0 (15/11/2026) και το έγγραφο «Σχέδιο κατασκευής website (Βήμα 1)».

## Τι υπάρχει σε αυτό το repository

| Φάκελος | Περιεχόμενο | Κατάσταση |
| --- | --- | --- |
| `supabase/migrations/` | Σχήμα βάσης, κανόνες πρόσβασης, ταξινομία (5 κόσμοι, 9 σειρές) | Ελεγμένο τοπικά σε PostgreSQL 16 |
| `supabase/tests/` | 69 έλεγχοι πρόσβασης και κανόνων δεδομένων | Περνούν όλοι τοπικά |
| `scripts/test-db.sh` | Στήνει προσωρινή βάση, τρέχει migrations και ελέγχους | — |
| `src/styles/tokens.css` | Παλέτα, γραμματοσειρές, κλίμακες | Εγκεκριμένα tokens |
| `public/fonts/` | Arimo και GFS Artemisia, με τις άδειες OFL | — |

Δεν υπάρχει ακόμη: η εφαρμογή Next.js (δημόσιες σελίδες και CMS), οι server endpoints για φόρμες και newsletter, η συλλογή events.

## Έλεγχος της βάσης

```bash
scripts/test-db.sh          # θέλει PostgreSQL 15+ εγκατεστημένη, όχι ως root
```

Οι έλεγχοι τρέχουν σε σκέτη PostgreSQL με ένα μικρό υποκατάστατο του Supabase (`supabase/tests/00_local_stub.sql`). **Δεν έχουν τρέξει ακόμη σε πραγματικό project Supabase.**

## Αποφάσεις που διαφέρουν από το blueprint

- **Δύο ρόλοι** (admin, editor) αντί για έξι. Ο editor γράφει και δημοσιεύει περιεχόμενο και κάνει moderation. Ο admin επιπλέον διαχειρίζεται ομάδα, πηγές events, συνεργάτες, leads και newsletter.
- **Αυτόματη δημοσίευση events από έμπιστες πηγές.** Η βάση το επιβάλλει: event από συλλογή δημοσιεύεται χωρίς άνθρωπο μόνο αν η πηγή του είναι ενεργή και έμπιστη. Όλα τα άλλα πάνε στην ουρά (`status = 'in_review'`).
- **Απλοποιήσεις:** ένα `events` αντί για EventSeries και EventOccurrence, `partners` χωρίς campaigns και placements, τεκμηρίωση ως πεδία (`source_url`, `checked_at`, `evidence_url`) αντί για ξεχωριστό πίνακα. Δεν υπάρχει ακόμη πίνακας εισαγωγής παλιάς βιβλιοθήκης.

## Κανόνες που επιβάλλει η βάση

- Ο επισκέπτης διαβάζει μόνο δημοσιευμένο περιεχόμενο που έχει έρθει η ώρα του, και media με ισχύοντα δικαιώματα.
- Υποβολές, leads και συναινέσεις newsletter γράφονται μόνο από τον server και δεν διαβάζονται ποτέ ανώνυμα.
- Ιστορία δεν δημοσιεύεται χωρίς σύνοψη, κόσμο, συντάκτη και κείμενο. Κάθε εμπορική σχέση θέλει συνεργάτη και ορατή ένδειξη.
- Event δεν δημοσιεύεται χωρίς ημερομηνία, χώρο και ημερομηνία ελέγχου. «Δωρεάν» σημαίνει επιβεβαιωμένο μηδενικό κόστος.
- Πρόταση Weekend έχει ακριβώς έναν στόχο και ποτέ ακυρωμένο event.
- Αλλαγή slug δημοσιευμένης σελίδας δημιουργεί redirect. Κάθε αλλαγή κρατά έκδοση στο ιστορικό.

## Πριν από production

- Κλειστή εγγραφή χρηστών στο Supabase Auth (δεν υπάρχουν δημόσιοι λογαριασμοί).
- Cron που καλεί `app.publish_due()` κάθε λίγα λεπτά.
- Εκτέλεση των ελέγχων σε πραγματικό project Supabase (staging).
- Μετατροπή των γραμματοσειρών σε WOFF2 για ταχύτητα.
